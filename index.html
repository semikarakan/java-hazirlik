MBP 205 - Nesne Tabanlı Programlama II (Java)

Tahta Notları, UML Diyagramları, Hocanın 5 Projesi ve Kağıt Üstü Vize Simülasyonu

1. Bölüm: NTP'nin 4 Temeli (Tahtadaki 1. Başlık)

Hocanın tahtanın sol tarafına yazdığı 4 ana sütun ve kodlardaki birebir karşılıkları:

A) Kalıtım (Inheritance) ve Override

  • Bir alt sınıfın (subclass), üst sınıfın (superclass) özellik ve metotlarını extends anahtar kelimesiyle miras almasıdır.
  • Tek Üst Sınıf Kuralı: Java'da bir sınıf extends ile en fazla 1 tane üst sınıftan miras alabilir.
  • Constructor (Yapıcı) Kuralı: Üst sınıfta parametreli constructor varsa (örneğin Karakter veya Gonderi sınıfı), alt sınıf kendi constructor'ının ilk satırında super(...) diyerek üst sınıfın constructor'ını çağırmak zorundadır!
  • Metot Ezme (Override): Üst sınıftaki bir metodun alt sınıfta yeniden tanımlanmasıdır. Üst sınıftaki orijinal metodu da çalıştırmak istersen super.kos(); veya super.bilgiGoster(); yazılır.
public class Tavsan extends Hayvan {
    @Override
    public void kos() {
        super.kos(); // Önce Hayvan sınıfındaki kos() çalışır
        System.out.println("Tavsan zipladi!");
    }
}

B) Kapsülleme (Encapsulation)

  • Sınıf özelliklerinin (değişkenlerin) dışarıdan doğrudan erişime kapatılması (private yapılması) ve kontrollü erişim için get / set metotlarının kullanılmasıdır.
  • Tahtadaki semboller: public (+), private (-), protected (#), package/default (~).
Erişim Belirleyici UML Sembolü Aynı Sınıf Aynı Paket Alt Sınıf (Kalıtım) Her Yerden

protected#EvetEvetEvetHayır

Kritik Sınav Notu: Insan.java içinde private int bakiye; tanımlandığı için, Musteri extends Insan olsa bile this.bakiye += miktar; yazamazsın! Hoca bunu kodda yorum satırı yapıp getBakiye() ve setBakiye(yeniBakiye) ile çözmüştür.

C) Soyutlama (Abstraction)

  • Kullanıcının bilmesine gerek olmayan iç işleyiş detaylarının gizlenip sadece gerekli arayüzün sunulmasıdır.
  • Kod Örnekleri: Insan sınıfındaki private String musteriNoOlustur() ve Karakter sınıfındaki private int savun() metotları dışarıdan gizlenmiştir; sadece sınıfın kendi içindeki metotlar tarafından çağrılır. Ayrıca abstract class ve interface yapıları da mimari soyutlama sağlar.

D) Çok-Biçimlilik (Polymorphism)

  • Üst sınıf (veya Interface) referansının, alt sınıf nesnelerini tutabilmesidir.
  • Tahtadaki örnekler: Hayvan h = new Kedi(); ve ArrayList<Hayvan> liste;
Insan insan = new Calisan("Ali");
Insan insan2 = new Musteri("Veli");
insan.bilgiGoster();  // Calisan'ın numarası (C...) ile çalışır
insan2.bilgiGoster(); // Musteri'nin numarası (M...) ile çalışır

// SINAV TUZAĞI:
// insan2.bakiyeGoster(); -> DERLEME HATASI (Compile Error)!
// Çünkü insan2'nin referans tipi Insan'dır ve Insan sınıfında bakiyeGoster() metodu yoktur!
// Çözümü (Downcasting):
((Musteri) insan2).bakiyeGoster();

Proje 1: Tavşan ve Kaplumbağa Yarışı (Düz Kod vs Kalıtım)

Hoca önce kalıtımsız versiyonu, ardından Hayvan üst sınıfıyla kalıtımlı versiyonu yazmıştır.

Kritik Noktalar:

  • Random r = new Random(); int zar = r.nextInt(1, 7); -> 1 dahil, 7 hariç (yani 1 ile 6 arası zar atar).
  • Switch-Case Düşmesi (Fall-through): Tavsan.java içinde case 2: altında break; yoktur, doğrudan case 3: içine düşer. Yani zar 2 veya 3 geldiğinde ekrana "Tavsan yemek yiyiyor!" yazar ve konum değişmez.
  • Beraberlik Kontrolü: Yaris.java içinde döngü bittiğinde ilk olarak if (t.konum >= PIST_UZUNLUGU && k.konum >= PIST_UZUNLUGU) kontrol edilir. Çünkü aynı turda ikisi de 100'ü geçebilir!
  • Kalıtımlı Versiyonda (Hayvan.java): String ad = this.getClass().getName(); kodu, metodu hangi nesne çağırdıysa onun sınıf adını (Tavsan veya Hayvan) döndürür.
// Hayvan.java
public class Hayvan {
    public int konum;
    public Hayvan() { konum = 6; }
    public Hayvan(int konum) { this.konum = konum; }
    public void kos() {
        String ad = this.getClass().getName();
        System.out.println(ad + " kosuyor");
    }
}

// Tavsan.java
public class Tavsan extends Hayvan {
    @Override
    public void kos() {
        super.kos(); // Ekrana "Tavsan kosuyor" yazar!
        System.out.println("Tavsan zipladi!");
    }
}

  • Insan constructor'ı içinde kullaniciNo = noOlustur(); çağrılır.
  • protected String noOlustur() metodu Musteri sınıfında "M" + 6 rakam, Calisan sınıfında "C" + 4 rakam üretecek şekilde @Override edilmiştir!
  • Sınav Sorusu Adayı: new Musteri("Veli") oluşturulduğunda, önce Insan constructor'ı çalışır ama noOlustur() override edildiği için Musteri'nin noOlustur() metodu devreye girer ve M ile başlayan numara atanır!
public class Insan {
    private String isim;
    private String kullaniciNo;

    public Insan(String isim){
        this.isim = isim;
        kullaniciNo = noOlustur(); // Alt sınıfta ezildiyse alt sınıfınki çalışır!
    }
    protected String noOlustur() { return null; }
    public void bilgiGoster(){
        System.out.println(kullaniciNo + " - " + isim);
    }
}

Proje 4: Soyut Sınıf (Hayvan), Kedi ve Arayüz İstisnaları

Tahtadaki private ve default arayüz metotlarının kodlandığı dosyadır (YemekYiyebilir.java):

public interface YemekYiyebilir {
    public final int YAS = 5; // public static final'dır
    String RENK = "Beyaz";    // Yazılmasa bile public static final'dır!

    public abstract void cigneme(); // Gövdesiz soyut metot
    void yutma();                   // Yazılmasa bile public abstract'tır!

    // İSTİSNA 1: Interface içinde private gövdeli metot (Java 9+)
    private void istina1(){
        System.out.println("Private metot kullanildi");
    }

    // İSTİSNA 2: Interface içinde default gövdeli metot (Java 8+)
    default void istisna2(){
        System.out.println("Bu bir default metot");
        istina1(); // private metodu kendi içinde çağırabilir
    }
}

Önemli: Kedi sınıfı YemekYiyebilir arayüzünü implements ettiğinde sadece cigneme() ve yutma() metotlarını @Override etmek zorundadır. istisna2() default olduğu için ezmek zorunda değildir!

Proje 5: Kargo Projesi (Soyut Sınıf + Çoklu Arayüz + Benzersiz Takip No)

Sınavda çıkma ihtimali en yüksek mimari şablondur:

public interface Sigortalanabilir {
    double standartSigortaUcreti = 100;
    double hizliSigortaUcreti = 500;
    void sigotaIslemiYap();
}

public interface TeslimEdilebilir {
    void teslimEt();
}

public abstract class Gonderi implements Sigortalanabilir, TeslimEdilebilir {
    protected String takipNo;
    protected double agirlik;
    protected boolean sigortaDurumu;
    protected boolean teslimDurumu;
    protected double ucret;

    public Gonderi(String takipNo, double agirlik) {
        this.takipNo = takipNo;
        this.agirlik = agirlik;
        this.sigortaDurumu = false;
        this.teslimDurumu = false;
        this.ucret = ucretHesapla(); // Alt sınıfın override ettiği metodu çağırır!
    }

    public abstract double ucretHesapla();
}

Kargo Projesindeki Kritik Noktalar:

  • Gonderi bir abstract class olduğu için Sigortalanabilir ve TeslimEdilebilir arayüzlerindeki sigotaIslemiYap() ve teslimEt() metotlarını kendisi ezmek zorunda kalmamıştır; bu sorumluluğu alt sınıfları olan StandartKargo ve HizliKargo'ya devretmiştir!
  • StandartKargo ücreti: this.agirlik * 25, sigortası: this.ucret += standartSigortaUcreti;
  • HizliKargo ücreti: this.agirlik * 40, sigortası: this.ucret += hizliSigortaUcreti;
  • Benzersiz (Unique) Takip No Üretimi: rasgeleTakipNoOlustur(String kargoSecim) metodu while(true) içinde S veya H harfine 4 rastgele rakam ekler, takipNoUniqueMi(takipNo) metoduyla kargolar listesini gezip aynı numara yoksa döndürür.

SORU 1 - KARGO PROJESİ GENİŞLETME (20 Puan)

Yeni Kargo Türü: KuryeKargo Sınıfını Yazınız

Kargo projesindeki Gonderi soyut sınıfından miras alan KuryeKargo sınıfını yazınız. Kurallar:

  • Constructor takipNo ve agirlik alıp üst sınıfa göndermelidir.
  • ucretHesapla() metodu agirlik * 60 + 50 değerini döndürmelidir.
  • sigotaIslemiYap() metodu ücrete hizliSigortaUcreti ekleyip sigortaDurumu'nu true yapmalıdır.
  • teslimEt() metodu ekrana bilgi yazdırıp teslimDurumu'nu true yapmalıdır.
public class KuryeKargo extends Gonderi {

    public KuryeKargo(String takipNo, double agirlik) {
        super(takipNo, agirlik);
    }

    @Override
    public double ucretHesapla() {
        return this.agirlik * 60 + 50;
    }

    @Override
    public void sigotaIslemiYap() {
        this.ucret += hizliSigortaUcreti;
        this.sigortaDurumu = true;
    }

    @Override
    public void teslimEt() {
        System.out.println(takipNo + " numarali kurye kargo teslim edildi.");
        this.teslimDurumu = true;
    }
}
SORU 2 - UML DİYAGRAMINDAN KODA DÖKME (20 Puan)

UML'de Verilen Yapıyı Java Koduna Çeviriniz

  • <<interface>> SarjEdilebilir : Sabit MAX_BATARYA : int = 100 ve gövdesiz + sarjEt() : void metodu.
  • <<abstract>> Arac : Özellik # plaka : String, parametreli constructor + Arac(plaka: String) ve soyut metot + menzilHesapla() : int.
  • ElektrikliArac : Arac sınıfından miras alır ve SarjEdilebilir arayüzünü uygular. Ek olarak - bataryaYuzdesi : int özelliğine sahiptir. Tüm zorunlu metotları uygular.
public interface SarjEdilebilir {
    int MAX_BATARYA = 100; // Otomatik public static final
    void sarjEt();         // Otomatik public abstract
}

public abstract class Arac {
    protected String plaka;

    public Arac(String plaka) {
        this.plaka = plaka;
    }

    public abstract int menzilHesapla();
}

public class ElektrikliArac extends Arac implements SarjEdilebilir {
    private int bataryaYuzdesi;

    public ElektrikliArac(String plaka, int bataryaYuzdesi) {
        super(plaka);
        this.bataryaYuzdesi = bataryaYuzdesi;
    }

    @Override
    public int menzilHesapla() {
        return this.bataryaYuzdesi * 4;
    }

    @Override
    public void sarjEt() {
        this.bataryaYuzdesi = MAX_BATARYA;
        System.out.println(this.plaka + " tam sarj edildi.");
    }
}

SORU 4 - TAVŞAN & KAPLUMBAĞA OOP DÖNÜŞÜMÜ (15 Puan)

Yarış Kodunu Soyut Sınıf ve Kapsülleme ile Yeniden Yazınız

Hocanın ilk derste verdiği Tavsan ve Kaplumbaga kodundaki public int konum; kapsülleme hatasını ve kod tekrarını gidermek için Yarisci adında bir abstract class yazınız. konum değişkeni private olsun, başlangıçta 0 atansın, getKonum(), setKonum(int konum) (konum 0'dan küçükse 0 yapılsın) ve gövdesiz public abstract void kos(); metodu bulunsun.

public abstract class Yarisci {
    private int konum;

    public Yarisci() {
        this.konum = 0;
    }

    public int getKonum() {
        return this.konum;
    }

    public void setKonum(int konum) {
        if (konum < 0) {
            this.konum = 0;
        } else {
            this.konum = konum;
        }
    }

    public abstract void kos();
}
SORU 5 - POLYMORPHISM VE ARRAYLIST KULLANIMI (15 Puan)

Kargo Listesinde Çok-Biçimli İşlem Metodu

ArrayList<Gonderi> kargolar listesini parametre olarak alan, listedeki henüz teslim edilmemiş (!kargo.teslimDurumu) tüm kargoları sigortalayan ve teslim eden topluIslemYap metodunu yazınız.

public void topluIslemYap(ArrayList<Gonderi> kargolar) {
    for (Gonderi kargo : kargolar) {
        if (!kargo.teslimDurumu) {
            kargo.sigotaIslemiYap();
            kargo.teslimEt();
        }
    }
}

  2. Hata 2: Sınıf tanımında implements kelimesi extends'ten önce yazılmış! Doğrusu: public class Kartal extends Kus implements Ucabilir.
  3. Hata 3: Kus sınıfında parametreli constructor (public Kus(String tur)) olduğu için Kartal() constructor'ının ilk satırında super("Kartal"); çağrısı yapılmak zorundadır.
  4. Hata 4: MAX_HIZ bir interface özelliğidir, yani public static final (SABİT) olduğu için MAX_HIZ = 500; şeklinde yeni değer atanamaz.
  5. Hata 5: Kus bir abstract class (soyut sınıf) olduğu için new Kus("Yirtici") şeklinde doğrudan nesnesi üretilemez!

Neden 2. satırda "Tavsan kosuyor" yazdı? Çünkü super.kos() çağrıldığında this.getClass().getName() o anki nesnenin gerçek sınıfını (Tavsan) döndürür!

Trace 2: Constructor İçinden Override Edilmiş Metot Çağırma (Insan & Musteri)

public class Insan {
    protected String kod;
    public Insan() {
        kod = olustur();
    }
    protected String olustur() { return "INS-0"; }
}
public class Musteri extends Insan {
    @Override
    protected String olustur() { return "MUS-99"; }
}
// Main:
Insan m = new Musteri();
System.out.println(m.kod);
MUS-99

Açıklama: new Musteri() oluşturulduğunda üst sınıfın (Insan) constructor'ı çalışır, ancak olustur() metodu Musteri sınıfında ezildiği (override) için çalışma zamanında Musteri'nin metodu çalışır! (Tıpkı hocanın Insan_2.java ve Gonderi.java kodlarındaki gibi).

Açıklama: istisna2() bir default metot olduğu için arayüz referansı üzerinden çağrılabilir ve kendi içinde private void istina1() metodunu çalıştırır. Ancak y.istina1(); satırı yorumdan çıkarılırsa private olduğu için Derleme Hatası verir!

Trace 4: Kapsülleme Koşul Kontrolü (Insan & Musteri Banka)

Musteri m = new Musteri(); // Insan() constructor'ında bakiye = 100

Adım Adım Takip:

  1. Başlangıç bakiyesi: 100.
  2. m.setBakiye(-500): if(bakiye >= 0) koşuluna takılır, bakiye değişmez (100 kalır).
  3. m.paraCek(120): 120 <= 100 olmadığı için ekrana Yetersiz Bakiye! yazar, bakiye 100 kalır.
  4. m.paraCek(40): 100 - 40 = 60 olur.
  5. m.paraEkle(-50): if(miktar > 0) koşuluna takılır, değişmez. Sonuç: 60.

Sınava Girmeden Önce Son Kontrol: Kağıtta Puan Kaybettiren 12 Altın Kural

  1. Sıralama: Önce extends, sonra implements yazılır: public class Kedi extends Hayvan implements YemekYiyebilir, Uyuyabilir
  2. Soyut Metot Noktalı Virgülü: abstract metotlarda ve interface soyut metotlarında süslü parantez {} açılmaz, sonuna ; konur: public abstract double ucretHesapla();
  3. Super İlk Satırda: Alt sınıf constructor'ında super(...) çağrısı her zaman 1. satırda olmak zorundadır.
  4. Interface Metotlarını Ezerken public Zorunluluğu: Bir interface içindeki void teslimEt(); aslında public abstract'tır. Bunu sınıfta ezerken başına mutlaka public yazmalısın (public void teslimEt()). Başına public yazmazsan erişim daraltıldığı için kod derlenmez!
  5. Interface Değişkenleri: Interface içinde tanımlanan tüm özellikler otomatik olarak public static final (SABİT) kabul edilir, ilk değer verilmek zorundadır ve sonradan değiştirilemez.
  6. Interface Gövdeli Metot İstisnası: Tahtadaki özel not! Interface içinde sadece default ve private anahtar kelimesi kullanılarak gövdeli metot yazılabilir.
  7. Constructor Farkı: abstract class içinde Constructor VARDIR; interface içinde Constructor YOKTUR. İkisinden de new ile nesne üretilemez ama ikisi de referans tipi olabilir!
  8. Polymorphism Referans Tuzağı: Insan i = new Musteri("Veli"); yazıldığında i üzerinden sadece Insan sınıfında tanımlı olan metotlar çağrılabilir. Musteri'ye özel metot için ((Musteri) i).bakiyeGoster(); yapılmalıdır.
  9. Private Değişkene Alt Sınıftan Erişim: Üst sınıftaki private değişkene alt sınıftan doğrudan erişilemez (this.bakiye hata verir). Doğrudan erişim isteniyorsa değişken protected (#) yapılmalı veya get/set kullanılmalıdır.
  10. UML Okları:
    • Düz çizgi + boş üçgen ok = Kalıtım (extends)
    • Kesikli çizgi + boş üçgen ok = Arayüz Gerçekleştirme (implements)
    • İçi boş elmas (◇) = Aggregation (Zayıf parça: Araba - Tekerlek)
    • İçi dolu elmas (◆) = Composition (Güçlü parça: İnsan - Kalp)
  11. String Karşılaştırması: Kargo takip numarası veya menü seçimlerini karşılaştırırken == değil, kargo.takipNo.equals(takipNo) kullanılır.
  12. Rastgele Sayı Üretimi: Random r = new Random(); nesnesinde r.nextInt(10) 0-9 arası üretir; r.nextInt(1, 7) ise 1-6 arası üretir (üst sınır dahil değildir).
